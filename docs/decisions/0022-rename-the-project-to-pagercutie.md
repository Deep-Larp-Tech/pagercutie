# ADR-0022: Rename the project to pagercutie

- **ID:** ADR-0022
- **Timestamp:** 2026-11-20T21:12+01:00
- **Status:** Accepted

## Decision

The scaffold names (`larp-stack`, `larper`, `larp` credentials) are replaced by `pagercutie` everywhere: Python package, compose project, images and database.

## Rationale

- One consistent name across code, containers and docs. The scaffold's LARP example domain stays until it is replaced.
