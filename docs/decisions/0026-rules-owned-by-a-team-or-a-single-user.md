# ADR-0026: Rules owned by a team or a single user

- **ID:** ADR-0026
- **Timestamp:** 2026-11-20T21:25+01:00
- **Status:** Accepted
- **See:** DOMAIN.md §3, §4

## Decision

A rule's owner is either a team or a user. Personal rules notify only their user and only see sources visible through the user's teams.

## Rationale

- The brief's "Anna (personal)" rule requires it.
